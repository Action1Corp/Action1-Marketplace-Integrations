# Action1 Configuration Manager

Action1 Configuration Manager is the Marketplace integration that will create and manage Windows configuration policies that assess and remediate endpoints through scheduled Action1 automations.

## Current Status

This package is a Slice 0 scaffold only. It is intentionally not operational yet.

## Included In This Slice

- Locked package identity and Marketplace metadata
- Policies and History route scaffolds
- No settings screen
- No integration-owned Action1 credentials
- Package-local scaffold regression tests

## Not Yet Implemented

- Policy authoring
- Persistence and migrations
- Action1 discovery
- Automation provisioning
- Reconciliation
